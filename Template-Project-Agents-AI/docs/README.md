# Framework Docs

Documentacion del framework SpecNative que no pertenece al contexto del
proyecto instalado.

## Objetivo

Separar claramente:

- contexto del proyecto destino
- reglas del framework
- tooling auxiliar del framework

## Contenido

- [`CLI.md`](./CLI.md):
  comandos de `tools/specnative.py`, validacion, exportacion e
  instalacion segura.
- [`ADOPTION.md`](./ADOPTION.md):
  como adoptar la plantilla en un repositorio existente sin mezclarlo
  con `agents/COMMANDS.md`.

## Regla

Todo lo que sea sobre el framework en si debe documentarse aqui.
`agents/COMMANDS.md` queda reservado para comandos del proyecto
adoptante.
